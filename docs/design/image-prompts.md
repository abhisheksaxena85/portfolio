# Image Prompts

> Generated by `yarn image:prompts` from `src/content/images.ts`. Do not edit by hand.
> 33 prompts to generate, 2 real photographs to supply. Style and review gate: [image-brief.md](./image-brief.md).

## How to run a prompt

1. Generate at 1.5× the export size listed (so a 1600×900 hero is made at 2400×1350), then downscale.
2. Check the result against the 8-point gate in image-brief.md §5 before saving. If it fails, change the prompt, do not retouch.
3. Export to the path in **File** as PNG. Set the record's `status` to `generated`, then `approved` after it is seen on the real page.
